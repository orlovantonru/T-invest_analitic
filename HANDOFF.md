## Архитектура

Подробно — [docs/STRUCTURE.md](docs/STRUCTURE.md). Коротко: Vite+React+TS
фронтенд + Node-прокси (`server/`) к T-Invest API, три режима (live / auth /

## Что сделано и сработало

1. **Живой портфель через T-Invest API** — локальный read-only Node-прокси
   (`server/tinvest.js`, `server/index.js`), фронт ходит только на `/api/*`.
   Все 5 вкладок + карточка бумаги рендерят реальные данные. Обнаружена и
   исправлена проблема с TLS: `*.tbank.ru` подписан «Russian Trusted Root CA»,
   которого нет в списке Node — решено через `https.request` со своим `Agent`
   (`russian-trusted-ca.pem` в репозитории).
2. **Приблизительная «Динамика»** — в API нет ряда «стоимость портфеля во
   времени», строим `P(t) = Σ wᵢ·rᵢ(t)` из свечей, с ресэмплингом рядов разной
   длины к общей сетке точек. Помечено в UI как приближение.
3. **Аутентификация** — `server/auth.js`: пароль как scrypt-хеш в
   `.env.production`, подписанная stateless-cookie, антибрутфорс. Выключена
   локально, когда пароль не задан.
4. **Docker-деплой** — `Dockerfile` (multi-stage, node:22-slim), `web` + `caddy`
   в `docker-compose.yml`, авто-HTTPS через Let's Encrypt.
5. **VPS настроен** — REG.RU (`157.22.187.241`, Ubuntu 24.04): пользователь
   `deploy` вместо root, вход только по SSH-ключу (`~/.ssh/portfolio`,
   локальный alias `ssh portfolio`), `ufw` (22/80/443), `fail2ban`.
6. **DNS** — домен `ant-invest.online` у REG.RU, A-записи `@` и `portfolio` →
   IP сервера.
7. **Git** — репозиторий переведён с ручной пересылки архивов на
   `git clone`/`git pull` с GitHub (`orlovantonru/T-invest_analitic`, публичный).
8. **Документация и комментарии** — `docs/STRUCTURE.md` (пофайловое описание +
   диаграмма потока данных), doc-комментарии на каждом файле `src/`/`server/`.
9. **UI-полировка** — убран фейковый статус-бар iOS (время/батарея, «чёлка»,
   home-indicator) из рамки телефона.
10. **`APP_DOMAIN` рефактор** — домен теперь берётся из переменной окружения
    (`.env.production` → `{$APP_DOMAIN}` в `Caddyfile`), вместо `sed`-правки
    `Caddyfile` при каждом деплое.

## Грабли — что не получилось с первого раза

- **`node --watch` + переменные окружения:** пытались перезапускать прокси при
  изменении `.env` через self-re-exec с `NODE_EXTRA_CA_CERTS` — не сработало
  чисто, в итоге CA подключили напрямую в `tinvest.js` через `https.Agent`
  (см. пункт 1 выше). Итоговое решение проще и надёжнее.
- **`PORT` как имя переменной** конфликтовало с переменной окружения самого
  dev-сервера (Vite/раннер) — переименовали в `PROXY_PORT`/`PROXY_HOST`.
- **Забытая passphrase SSH-ключа** — ключ `id_ed25519` стал непригоден
  (`Bad passphrase`), пришлось сгенерировать новый (`~/.ssh/portfolio`, без
  фразы) и переставить публичную часть на сервер, пока ещё был доступ по паролю.
- **`fail2ban` банил домашний IP** несколько раз подряд во время тестов входа
  (динамический IP + много неудачных попыток). Решение — whitelist
  (`/etc/fail2ban/jail.d/whitelist.local`, `ignoreip`) + смягчённые
  `maxretry`/`bantime` для `sshd`. **Если IP провайдера снова сменится — тот
  же симптом (`Connection closed by ... port 22`) повторится**, чинить так же
  через консоль VPS (см. DEPLOY.md → «Диагностика проблем»).
- **`sshd_config.d/40-hosting.conf`** от хостера форсил `PasswordAuthentication
  yes` и перебивал наши настройки (читается раньше по алфавиту) — переименовали
  свой файл в `00-hardening.conf`, чтобы читался первым.
- **Провайдерский `coolify.io/uninstall.sh` недоступен** — Coolify (стоял на
  VPS изначально, занимал порты 80/443/8000) снесли вручную (контейнеры +
  сеть + `/data/coolify`), не официальным скриптом.
- **Токен T-Invest переиздавался несколько раз** — один раз случайно попал в
  отслеживаемый `.env.example` и в переписку, пришлось отзывать и перевыпускать.
  Текущий токен — только в `app/.env` (локально) и `.env.production` (на
  сервере), оба в `.gitignore`.

## Известные ограничения (осознанные, не баги)

- «Динамика» в live — **приближение** (см. выше), не точная историческая
  стоимость портфеля.
- Линии инфляции в live нет (нет источника в API).
- Произвольный диапазон дат на «Динамике» — только в демо-режиме.
- Сектор и купоны облигаций подгружаются лениво — при первом открытии
  вкладки/карточки может быть небольшая задержка.

  ```bash
  cd ~/mobinvest/app && git pull && docker compose up -d --build && docker image prune -f
  ```

  compose up -d`.

  с `TINVEST_TOKEN` в `app/.env`).
